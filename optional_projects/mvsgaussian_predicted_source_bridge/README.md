# MVSGaussian Predicted-Source Diffusion Bridge

This optional bridge shows how to migrate ADO-NeRF's scene-consistent diffusion repair workflow to MVSGaussian without using raw or ground-truth source-view MVS depths as diffusion conditions.

The bridge corresponds to the predicted-source MVSGaussian export path. Source-view depths are predicted by MVSGaussian itself through extra depth-only forward passes, then packed into diffusion tensors.

## Files

```text
export_mvsgs_predicted_source_depth.py       MVSGaussian export entry point
mvsgs_diffusion_export_utils.py              Tensor packing, masks, cameras, depth completion
diffusion_nerf/depth_completion_utils.py     MVS/mono depth fusion utilities
diffusion_nerf/refine_mvsgs_scene_consistent.py
diffusion_nerf/refine_mvsgs_frequency_blending.py
diffusion_nerf/mvsgs_refinement_metrics.py
```

`refine_mvsgs_scene_consistent.py` is the recommended refinement entry point. `refine_mvsgs_frequency_blending.py` is kept as an optional frequency-blending variant for comparison.

## Copy Into MVSGaussian

From the ADO-NeRF repository:

```bash
BRIDGE=optional_projects/mvsgaussian_predicted_source_bridge
MVSGS=/path/to/MVSGaussian

cp "$BRIDGE/export_mvsgs_predicted_source_depth.py" "$MVSGS/"
cp "$BRIDGE/mvsgs_diffusion_export_utils.py" "$MVSGS/"
cp "$BRIDGE/diffusion_nerf/depth_completion_utils.py" "$MVSGS/diffusion_nerf/"
cp "$BRIDGE/diffusion_nerf/refine_mvsgs_scene_consistent.py" "$MVSGS/diffusion_nerf/"
cp "$BRIDGE/diffusion_nerf/refine_mvsgs_frequency_blending.py" "$MVSGS/diffusion_nerf/"
cp "$BRIDGE/diffusion_nerf/mvsgs_refinement_metrics.py" "$MVSGS/diffusion_nerf/"
```

The diffusion checkpoint folders should follow the same layout used by ADO-NeRF:

```text
MVSGaussian/diffusion_nerf/check_points/
  pretrained_model/
  Stable-Diffusion-2-1-base/
```

## Export Diffusion Tensors

Run the export from the MVSGaussian repository root:

```bash
cd /path/to/MVSGaussian
export workspace=$(pwd)

MVSGS_DIFFUSION_OUTPUT_DIR=diffusion_nerf/mvsgs_predicted_source_inputs \
MVSGS_DIFFUSION_EXPORT_LIMIT=0 \
python export_mvsgs_predicted_source_depth.py \
  --type evaluate \
  --cfg_file configs/mvsgs/dtu_pretrain.yaml \
  exp_name <mvsgs_experiment_name> \
  test.epoch <checkpoint_epoch>
```

The exporter writes one tensor per target view:

```text
diffusion_nerf/mvsgs_predicted_source_inputs/<scene>_<view>_<frame>_<index>_diffusion_data.pt
```

Preview images and mask/depth visualizations are written next to the tensors to make export inspection easier.

## Run Diffusion Repair

Recommended scene-consistent repair:

```bash
cd /path/to/MVSGaussian/diffusion_nerf

python refine_mvsgs_scene_consistent.py \
  --input_dir mvsgs_predicted_source_inputs \
  --experiment_root mvsgs_scene_consistent_results \
  --depth_mode source \
  --mask_profile orig
```

Optional frequency-blending variant:

```bash
python refine_mvsgs_frequency_blending.py \
  --input_dir mvsgs_predicted_source_inputs \
  --output_dir mvsgs_frequency_blending_results \
  --depth_mode source
```

Use `--limit 1` for a quick local check before a full evaluation.

## Tensor Contract

The exported `*_diffusion_data.pt` file contains the fields used by the diffusion repair scripts:

```text
source_rgbs
pred_rgb
source_depths
source_valid_masks
source_mvs_depths
source_complete_depths
blur_mask
mask_layer1_raw
mask_layer2_soft
mask_layer3_raw
mvs_depth / target_mvs_depth
intrinsics
extrinsics_w2c
extrinsics_c2w
extrinsics_format
cond_num
source_depth_origin
uses_source_raw_depth
```

`uses_source_raw_depth` is always `False` for this bridge. The helper raises an error if `src_mvs_depths_level{level}` is missing, so the export cannot silently fall back to raw dataset depths.

## Required MVSGaussian Outputs

Checked against the MVSGaussian network source, the base model already returns the target-view fields needed by the bridge:

```text
rgb_level{level}
depth_mvs_level{level}
std_level{level}
```

No permanent change to `lib/networks/mvsgs/network.py` is required for this predicted-source bridge. The export script adds source-view fields outside the main network forward pass by reusing MVSGaussian's feature extractor, cost-regularization modules, and depth regression:

```text
src_mvs_depths_level{level}
src_mvs_stds_level{level}        optional
source_depth_origin
```

For a different but similar model, add or export the same information:

- Target rendered RGB at the repair resolution.
- Target MVS depth and optional uncertainty.
- Per-source predicted MVS depth, generated by the model from each source camera as target.
- Source RGBs, camera intrinsics, and world-to-camera extrinsics.
- A repair mask and, if mask recomposition is needed, separate mask layers.

Do not use `src_dpts`, `src_msks`, or other dataset raw source-depth supervision as diffusion conditions when reproducing this predicted-source setting.

## Mask Notes

Use `--mask_profile orig` when visual naturalness is the priority. Use `--mask_profile ado_tuned` when a stronger metric-oriented mask is desired. Mask recomposition weights and post-scaling are model-sensitive, so MVSGaussian-like models may need their own parameter search.
